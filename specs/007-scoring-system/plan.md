## Summary

Add a 1–5 dimension scoring system to the pipeline review workflow. Admins optionally score each idea across five fixed dimensions (Innovation, Feasibility, Business Impact, Strategic Alignment, Technical Soundness) when advancing or rejecting at any pipeline stage. Scores are persisted in a new `evaluation_scores` table linked to stage transitions, displayed as a per-stage and overall summary on the review page, and aggregated as a single badge score on the admin idea list.

## Technical Context

**Testing**: Jest 29 + React Testing Library (unit + integration), Playwright (E2E)  
**Target Platform**: Web — same Next.js RSC + client-component pattern as existing pipeline features  
**Project Type**: Web application (Next.js App Router, full-stack)  
**Performance Goals**: Score summary loads within 1s for ideas with ≤20 transitions; admin list aggregate adds <50ms to existing query time  
**Constraints**: No new npm packages; TypeScript strict mode; zero ESLint warnings; SQLite WAL mode  
**Scale/Scope**: Single-tenant; up to ~1000 ideas; up to 20 stage transitions per idea × 5 dimensions = ≤100 score rows per idea
