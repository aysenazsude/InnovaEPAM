## Schema Changes

### New Table: `evaluation_scores`

One row per scored dimension per stage transition. Scores are immutable once written.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | TEXT | PRIMARY KEY | UUID generated by application |
| `idea_id` | TEXT | NOT NULL, FK → ideas.id ON DELETE CASCADE | Denormalised for efficient per-idea queries |
| `stage_transition_id` | TEXT | NOT NULL, FK → stage_transitions.id ON DELETE CASCADE | Links score to the specific transition event |
| `admin_id` | TEXT | NOT NULL, FK → users.id | Admin who submitted the scores |
| `dimension` | TEXT | NOT NULL, CHECK(dimension IN (...)) | One of the 5 fixed dimension keys (see below) |
| `score` | INTEGER | NOT NULL, CHECK(score >= 1 AND score <= 5) | Whole number 1–5 |
| `created_at` | INTEGER | NOT NULL | Unix timestamp (seconds) |

**Unique constraint**: `(stage_transition_id, dimension)` — one score per dimension per transition.  
**Indexes**:
- `idx_evaluation_scores_idea_id` on `idea_id` — for per-idea summary queries
- `idx_evaluation_scores_transition_id` on `stage_transition_id` — for per-transition lookup

### Fixed Evaluation Dimensions

| Dimension key | Display name |
|--------------|--------------|
| `innovation` | Innovation |
| `feasibility` | Feasibility |
| `business_impact` | Business Impact |
| `strategic_alignment` | Strategic Alignment |
| `technical_soundness` | Technical Soundness |

Defined as a constant `SCORING_DIMENSIONS` in `src/lib/constants.ts`.

## No Existing Table Changes

- `stage_transitions`: unchanged — scores reference transitions, not the reverse.
- `ideas`: unchanged — aggregate score is computed at read time; not persisted.
- `users`, `attachments`, `drafts`, `clarification_requests`: unchanged.

## TypeScript Types (additions to `src/lib/db/schema.ts`)

```typescript
export const SCORING_DIMENSION_VALUES = [
  'innovation',
  'feasibility',
  'business_impact',
  'strategic_alignment',
  'technical_soundness',
] as const;

export type ScoringDimension = typeof SCORING_DIMENSION_VALUES[number];

export const evaluationScores = sqliteTable(
  'evaluation_scores',
  {
    id: text('id').primaryKey(),
    ideaId: text('idea_id')
      .notNull()
      .references(() => ideas.id, { onDelete: 'cascade' }),
    stageTransitionId: text('stage_transition_id')
      .notNull()
      .references(() => stageTransitions.id, { onDelete: 'cascade' }),
    adminId: text('admin_id')
      .notNull()
      .references(() => users.id),
    dimension: text('dimension', { enum: SCORING_DIMENSION_VALUES }).notNull(),
    score: integer('score').notNull(),
    createdAt: integer('created_at').notNull(),
  },
  (table) => [
    uniqueIndex('idx_evaluation_scores_transition_dimension')
      .on(table.stageTransitionId, table.dimension),
    index('idx_evaluation_scores_idea_id').on(table.ideaId),
    index('idx_evaluation_scores_transition_id').on(table.stageTransitionId),
  ]
);

export type EvaluationScore = typeof evaluationScores.$inferSelect;
export type NewEvaluationScore = typeof evaluationScores.$inferInsert;
```

## Migration

**File**: `src/lib/db/migrations/0005_scoring_evaluation.sql`

```sql
CREATE TABLE evaluation_scores (
  id TEXT PRIMARY KEY,
  idea_id TEXT NOT NULL REFERENCES ideas(id) ON DELETE CASCADE,
  stage_transition_id TEXT NOT NULL REFERENCES stage_transitions(id) ON DELETE CASCADE,
  admin_id TEXT NOT NULL REFERENCES users(id),
  dimension TEXT NOT NULL CHECK(dimension IN (
    'innovation', 'feasibility', 'business_impact',
    'strategic_alignment', 'technical_soundness'
  )),
  score INTEGER NOT NULL CHECK(score >= 1 AND score <= 5),
  created_at INTEGER NOT NULL,
  UNIQUE(stage_transition_id, dimension)
);

CREATE INDEX idx_evaluation_scores_idea_id ON evaluation_scores(idea_id);
CREATE INDEX idx_evaluation_scores_transition_id ON evaluation_scores(stage_transition_id);
```
