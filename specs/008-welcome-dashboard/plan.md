# Implementation Plan: Welcome Dashboard

**Branch**: `008-welcome-dashboard` | **Date**: 2026-05-15 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `/specs/008-welcome-dashboard/spec.md`

---

## Summary

Build a personalised welcome page at `/home` for submitter-role users showing system-wide idea statistics, per-user submission stats, the most recent submission with live status, and quick-action links. No new DB tables or migrations are needed — all data is derived from the existing `ideas` table. `getRoleHome('submitter')` is updated to route post-login traffic to `/home`.

---

## Technical Context

**Language/Version**: TypeScript 5 / Node.js 20  
**Primary Dependencies**: Next.js App Router, React 19, Tailwind CSS, Drizzle ORM + better-sqlite3  
**Storage**: SQLite via Drizzle ORM; existing `ideas` table (no new tables)  
**Testing**: Jest 29 + React Testing Library (unit/integration), Playwright (E2E)  
**Target Platform**: Web — Next.js SSR (RSC + server actions)  
**Project Type**: Web application — portal feature page  
**Performance Goals**: Page load < 2 s; stats queries execute in a single round-trip (two parallel SQL aggregations)  
**Constraints**: No new npm packages; zero TypeScript errors; zero ESLint warnings; files ≤ 300 lines  
**Scale/Scope**: Single page, 3 new components, 1 new server action, 2 existing file modifications

## Phase 1: Design

### Data model → [data-model.md](data-model.md)

```typescript
// src/lib/actions/dashboard.ts

export interface SystemStats {
  totalSubmitted: number;
  totalApproved: number;
  totalInPipeline: number;
}

export interface UserStats {
  totalSubmitted: number;
  totalApproved: number;
  totalPending: number;
}

export interface LastSubmission {
  id: string;
  title: string;
  status: string;
  submittedAt: number;
}

export interface DashboardData {
  systemStats: SystemStats;
  userStats: UserStats;
  lastSubmission: LastSubmission | null;
}

export async function getDashboardData(dbInstance?: DB): Promise<DashboardData>
```

### Interface contracts → [contracts/dashboard-api.md](contracts/dashboard-api.md)

Component prop interfaces:

```typescript
// StatsRow
interface StatsRowProps { stats: SystemStats }

// UserStatsPanel  
interface UserStatsPanelProps {
  userStats: UserStats;
  lastSubmission: LastSubmission | null;
  userName: string;
}

// QuickActions — no dynamic props
interface QuickActionsProps {}
```

Navigation change:
- `getRoleHome('submitter')`: `/ideas` → `/home`
- Nav: `Home → /home` added as first submitter nav link

### Page structure (`/home`)

```
<main>
  <h1>Welcome, {userName}</h1>

  <!-- US2: System-wide stats (all users) -->
  <section aria-label="portal statistics">
    <StatsRow stats={systemStats} />
  </section>

  <!-- US1: Personal stats (submitters) -->
  <section aria-label="your activity">
    <UserStatsPanel
      userStats={userStats}
      lastSubmission={lastSubmission}
      userName={userName}
    />
  </section>

  <!-- US3: Quick actions -->
  <QuickActions />
</main>
```

### `StatsRow` — 3 stat cards

| Card label | Value source | Zero state |
|---|---|---|
| Total Ideas | `systemStats.totalSubmitted` | Shows `0` |
| Approved | `systemStats.totalApproved` | Shows `0` |
| In Pipeline | `systemStats.totalInPipeline` | Shows `0` |

### `UserStatsPanel` — personal section

- If `userStats.totalSubmitted === 0`: render zero state with "Submit Your First Idea" CTA
- Else: render 3 mini-stats (submitted, approved, pending) + `LastSubmissionCard` sub-component

### `QuickActions` — buttons

| Button | Destination | Variant |
|---|---|---|
| Submit New Idea | `/ideas/new` | primary |
| View All My Ideas | `/ideas` | outline |
